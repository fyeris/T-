⚔ フェリスのプロフィール＆チャットサイト ⚔

コード手打ち練習中の「フェリス」の自己紹介ページと、簡単な会話ができるチャットルームを組み合わせたWebサイトです。

📁 ファイル構成

├── index.html       # プロフィール画面（メインページ）
├── chat.html        # フェリスとのチャットルーム画面
├── script.js        # チャット機能・お問い合わせフォームの動作処理
└── css/
    ├── style.css    # プロフィール画面専用のスタイルシート
    └── chat.css     # チャット画面専用のスタイルシート


✨ 主な機能

1. プロフィール画面 (index.html)

基本情報・好きなこと・ひとこと: フェリスのパーソナル情報を紹介しています。

仮作成週間スケジュール: 1週間の予定をまとめたテーブル表です。

お問い合わせフォーム: メッセージの送信（擬似送信完了メッセージの表示）ができます。

2. チャットルーム画面 (chat.html)

入力したメッセージに対して、フェリスが返信してくれます。

反応するキーワード例:

「こんにちは」「やあ」「おはよう」

「年齢」「何歳」

「出身」「どこ」

「趣味」「好き」「ゲーム」

「寝不足」「徹夜」「眠い」

※上記以外の言葉にもランダムで返信します。

🚀 使い方

上記のファイル構成通りにフォルダとファイルを配置します。

index.html をブラウザ（Chrome, Edge, Safariなど）で開きます。

ヘッダーの「💬 チャットで話す」ボタンからチャット画面へ移動できます。
